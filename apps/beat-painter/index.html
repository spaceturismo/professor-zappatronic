Click or drag across the grid to place notes. Every instrument has five rows. In the melodic instruments higher rows are higher notes. Pad and Keys play a full chord for each note. In the drums, higher rows are higher-pitched, shorter versions of the same drum (the middle row is the classic sound). Space plays and stops.

      Import

      Open a file

      MIDI (.mid), audio (.wav, .mp3, and similar), a Beat Painter song file, or the .zip from Save audio + MIDI. You can also drop a file anywhere on this page.

      Audio is analysed for its tempo and its kick, snare and hi-hat hits, so it works best on drum loops and beats.

      Choose a file

      Paste a code or type a pattern

      Paste a song code, or write notes as text, one instrument per line: kick: x...x...x...x... (x is a hit, a dot is a rest, 1 to 5 picks the row, 32 characters make two bars). Optional lines: bpm: 120, key: A, scale: Hirajoshi.

      Export

      Video

      Records the animation together with the beat, live, so it takes as long as the music plays. Then you can watch it and save it.
